Desktop and game streaming client for LG webOS

  • Video. Up to 4K120 with HDR. HEVC or H.264, decoded by the TV's hardware media pipeline.
  • Bitrate. Automatic mode adjusts to the network, or set a fixed rate from 10 to 200 Mbps.
  • Audio. Stereo, 5.1 or 7.1, decoded on the TV.
  • Per-game overrides. Any game can override the global resolution, frame rate, bitrate, codec, HDR, audio or controller settings.
  • Input. Magic Remote pointer, gamepads, USB keyboard and mouse. Pointer capture for games, absolute pointing for the desktop, gestures.
  • DualSense. Adaptive triggers, lightbar, player LEDs, touchpad, gyro and rumble over Bluetooth. Older webOS kernels predate the PlayStation driver, so some features are unavailable there.
  • Host power. Wake-on-LAN starts a sleeping host from the TV, and a paired host can be put to sleep or shut down on exit when it grants those rights.
  • Game mode (rooted TVs). Optional setting that switches picture and sound to Game mode while streaming and restores the previous settings on exit.

Best on webOS 5 or later. webOS 3.5–4.x is supported through a fallback decode path, with limits: no HDR (SDR only), H.264 only (no HEVC) and stereo audio only.

Requires a punktfunk host running on your PC. See the host setup guide.
